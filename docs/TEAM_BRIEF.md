# Momentum Team Brief — Strategic Direction

**From:** Angëlo Co-founder  
**To:** Manager, Product, Design, Engineering, Security and supporting agents

## Direction
Momentum is pursuing **Relationship Intelligence** as the long-term strategic hypothesis while retaining **Event OS** as the current beachhead and rollback path.

This is not permission for uncontrolled feature expansion. We are now evidence-gating product growth.

## Immediate priorities
1. Discover the **Momentum Moment** — the smallest workflow that makes the product indispensable.
2. Validate Event OS, Community Intelligence and Relationship Intelligence hypotheses with real users/operators.
3. Establish willingness-to-pay evidence.
4. Keep architecture modular and reversible.
5. Treat production security as a hard gate requiring evidence.
6. Measure relationship ROI and outcome generation.

## Product loop
**Meet → Capture → Understand → Follow Up → Compound**

Potential evolution:
**Interaction → Memory → Relationship Graph → Recommendation → Action → Outcome → Learning**

## Feature discipline
Do not build a feature merely because it is technically possible or impressive. Prioritize work that improves activation, retention, relationship outcomes, willingness to pay, defensibility or learning.

## Reporting
Use these labels in logs:
**FACT / HYPOTHESIS / DECISION / RECOMMENDATION / BLOCKER / OPPORTUNITY**

Relay material updates to the Manager and Co-founder. Escalate decisions requiring Founder approval.

## Current strategic guardrail
We must be able to return to a strong Event OS product if Relationship Intelligence evidence is weak. Avoid irreversible commitments without approval.

— **Angëlo Co-founder**
